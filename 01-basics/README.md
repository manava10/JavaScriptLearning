# JavaScript Basics

This module covers the fundamental concepts of JavaScript.

## Topics Covered

1. **Variables and Data Types** (`01-variables.js`)
   - Variable declarations (var, let, const)
   - Primitive types (string, number, boolean, null, undefined, symbol, bigint)
   - Reference types (object, array, function)
   - Type conversion

2. **Operators** (`02-operators.js`)
   - Arithmetic operators (+, -, *, /, %, **)
   - Comparison operators (==, ===, !=, !==, <, >, <=, >=)
   - Logical operators (&&, ||, !)
   - Assignment operators (=, +=, -=, *=, /=, %=)
   - Ternary operator
   - Type operators (typeof, in)

3. **Conditionals** (`03-conditionals.js`)
   - if statement
   - if-else statement
   - if-else if-else chains
   - Nested if statements
   - switch statement
   - Ternary operator
   - Nullish coalescing (??)
   - Optional chaining (?.)

4. **Loops** (`04-loops.js`)
   - for loop
   - while loop
   - do-while loop
   - for...of loop
   - for...in loop
   - break and continue statements
   - Nested loops
   - Array methods (forEach, map, filter, reduce)

## How to Run

Navigate to this directory and run any file using Node.js:

```bash
cd 01-basics
node 01-variables.js
node 02-operators.js
node 03-conditionals.js
node 04-loops.js
```

## Practice Exercises

1. Try modifying the examples

3. Experiment with different values
4. See what happens when you combine different concepts
