# JavaScriptLearning

A comprehensive repository for learning JavaScript from basics to advanced concepts.

## 📚 Learning Path

This repository is organized into different modules to help you learn JavaScript step by step:

### 1. Basics
- Variables and Data Types
- Operators
- Conditionals (if/else, switch)
- Loops (for, while, do-while)

### 2. Functions
- Function declarations and expressions
- Arrow functions
- Parameters and arguments
- Return values
- Scope and closures

### 3. Objects
- Object literals
- Object properties and methods
- `this` keyword
- Object destructuring

### 4. Arrays
- Array methods (map, filter, reduce, etc.)
- Array destructuring
- Spread and rest operators

### 5. Asynchronous JavaScript
- Callbacks
- Promises
- Async/Await
- Fetch API

### 6. Advanced Topics
- ES6+ features
- Modules
- Error handling
- Regular expressions

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/manava10/JavaScriptLearning.git
   cd JavaScriptLearning
   ```

2. Install dependencies (if needed):
   ```bash
   npm install
   ```

3. Navigate to any topic folder and start learning!

## 💡 How to Use This Repository

- Each folder contains JavaScript files with examples and exercises
- Read the code comments to understand concepts
- Try modifying the code and see what happens
- Run the files using Node.js: `node filename.js`

## 🛠️ Prerequisites

- Basic understanding of programming concepts
- Node.js installed on your machine (to run JavaScript files)
